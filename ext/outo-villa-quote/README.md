# Outo Villa 報價 擴充功能 安裝說明

這個 Chrome 擴充功能讓「Outo 峇里島別墅空房查詢」頁面顯示 Villa Finder 的即時報價（含各房數），並把查到的報價分享給全公司。沒裝的人也會看到同事查過的報價，但要看即時報價就要裝。

## 安裝（約 2 分鐘）

1. 把 `outo-villa-quote-1.2.1.zip` 解壓縮，放在不會刪掉的地方（例如「文件」資料夾）。解壓後會有一個 `outo-villa-quote` 資料夾。
2. Chrome 網址列輸入 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選剛才的 `outo-villa-quote` 資料夾。列表會出現「Outo Villa 報價 1.2.1」。
4. 在這張卡片按「詳細資料」→ 往下找「擴充功能選項」→ 貼上 Andrew 給你的共享金鑰 → 儲存。
5. 用同一個 Chrome 登入 Villa Finder 官網（www.villa-finder.com）一次，之後保持登入。
6. 打開查詢頁 https://outo-bali-villas.vercel.app ，輸入日期後，右上角會出現「正在向 Villa Finder 取得 N 間即時報價…」，幾十秒後變成「VF 即時報價 N 間」，卡片價格標「VF 即時報價」就成功了。

## 為什麼會多一個 Villa Finder 分頁

1.2.0 起，擴充功能查價時會用一個 villa-finder.com 的分頁（已開著某間別墅的頁面就借用，沒有就自己開一個釘選、不會切換過去的別墅頁分頁）。這是因為 Villa Finder 從 2026-10-21 起只接受從自家別墅頁面發出的報價請求，擴充功能直接查會被擋（403）。那個分頁不要關；關了下次查價會再自動開。

## 一小時只能查 10 間

Villa Finder 從 2026-11 起限制查價頻率：同一台電腦大約每小時 12 筆，超過就封鎖 1 小時（2026-11-03 實測）。所以 1.2.1 起：

- 每次換日期，最多查 10 間（排在最前面、有空房的），一間間慢慢查（每 5 秒一間）。
- 一小時內最多查 10 間；用完右上角會顯示「這小時的查價額度用完了」，已查到的報價照常顯示。
- 萬一被 VF 封鎖，右上角會顯示「約 N 分鐘後才能再查」，期間不會再送請求（再送只會延長封鎖）。
- 同事查過的報價（標「VF 報價」）不吃你的額度。先用篩選條件把範圍縮小，再看即時報價。

## 畫面上的標籤是什麼意思

| 標籤 | 意思 | 準確度 |
|---|---|---|
| VF 即時報價 | 你自己的瀏覽器剛向 Villa Finder 查到的，30 分鐘內有效 | 等於 VF 網站報價 |
| VF 報價 | 同事近 7 天查過同一間、同樣日期的報價 | 等於查當時的 VF 報價，價格有變會由系統自動作廢重查 |
| VF 探價推算 | 沒有人查過這個日期，用這間別墅其他日期的探價結果推算（價目表＋固定費，或最近的入住樣本） | 多數在 1 美元內，少數差幾美元；報給客人前請用即時報價再確認 |
| 官網直售價 | 只有價目表，還沒有任何 VF 資料 | 可能漏掉固定費與促銷條件 |

右上角若出現「擴充功能還沒設共享金鑰」，代表第 4 步沒做：你還是看得到即時報價，但不會分享給同事。

## 背景探價（已暫停）

原本查詢頁開著時會在背景向 Villa Finder 探價，讓「VF 探價推算」越來越準。因為 VF 每小時只放行約 12 筆，1.2.1 起暫停背景探價，額度全留給即時報價；已探到的資料照常用來推算。

## 常見問題

- 右上角顯示「Villa Finder 限制查價頻率」或「額度用完」：等提示的分鐘數再查；不要一直換日期重試。
- 卡片一直停在「正在取得…」：每間約 5 秒，10 間約 1 分鐘；超過 2 分鐘再確認 Villa Finder 有登入、擴充功能沒被停用；重新整理頁面。
- 右上角顯示「Villa Finder 拒絕查價（403）」：代表 VF 又改了規則，請告訴 Andrew；或你是 1.1.x 舊版，請更新到 1.2.1。
- 右上角顯示「找不到可用的 Villa Finder 分頁」：手動開一次任何一間別墅的 Villa Finder 頁面再重新整理查詢頁。
- 報價顯示「VF 顯示不可訂」：Villa Finder 的報價 API 回報這組日期不可訂，和房況日曆不一定同步，以 VF 為準。
- 更新版本：Andrew 會給新的 zip，解壓縮覆蓋原本的資料夾後，到 `chrome://extensions` 按該卡片的 ↻。金鑰不用重貼。
- 擴充功能只對 villa-finder.com 和查詢頁有權限，不會讀其他網站。
